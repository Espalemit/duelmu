Kebijakan Privasi Duelmu

Berlaku sejak 8 November 2026 · Versi aplikasi 0.2.0

  • Tanpa akun. Tidak ada login, registrasi, atau profil. Semua pemain adalah Guest.
  • Tanpa server. Aplikasi tidak mengirim data ke server mana pun dan tidak memakai kuota internet. Main bareng berjalan langsung antar-HP lewat Wi-Fi/hotspot lokal atau Bluetooth.
  • Tanpa iklan, analitik, atau pelacakan.
  • Semua data tersimpan di perangkatmu dan dapat dihapus kapan saja.

Duelmu tidak meminta email, nomor telepon, tanggal lahir, sekolah, lokasi, foto, atau kontak. Jangan memakai data pribadi sebagai nama panggilan.

Izin perangkat

Akses jaringan (INTERNET) karena Android mewajibkannya untuk socket lokal antar-HP di Wi-Fi/hotspot yang sama; tidak ada koneksi ke server internet. Perangkat sekitar/Bluetooth (Android 12+) untuk menghubungkan HP lewat Bluetooth; hasil pemindaian tidak dipakai untuk menentukan lokasi. Lokasi hanya pada Android 8–11, karena sistem mewajibkannya untuk memindai perangkat Bluetooth; diminta hanya saat menekan “Pindai HP sekitar” dan tidak dibaca atau disimpan. Getar untuk umpan balik opsional.

Penyimpanan dan penghapusan

Riwayat disimpan di database lokal, dikecualikan dari cadangan cloud. Hapus melalui Pengaturan → Hapus riwayat / Hapus nama terakhir, atau dengan menghapus aplikasi.

Keamanan

Jalur Bluetooth terenkripsi (secure RFCOMM). Jalur Wi-Fi/hotspot tidak dienkripsi; isinya hanya nama panggilan, jawaban, dan skor. Masuk room Wi-Fi memerlukan kode 4 digit dari HP Host, dan Host dapat mengeluarkan pemain.

Layanan Firebase

Developer memakai Firebase (paket Spark) hanya untuk App Distribution (mengirim versi beta ke penguji yang diundang) dan Hosting untuk halaman ini. Tidak ada Firebase SDK di dalam aplikasi.
